# Siber Güvenlik Blogu 💻🔒

Bu proje, **PHP ve Bootstrap kullanarak geliştirdiğim bir siber güvenlik blog sitesidir**.  
Blog, temel web geliştirme ve güvenlik uygulamalarını öğrenmek amacıyla yapılmıştır.

---

## 🎯 Proje Amacı
- Kullanıcıların hesap oluşturup giriş yapabileceği bir blog sistemi oluşturmak  
- Admin paneli ile gönderi ekleme, düzenleme ve silme işlemlerini yönetmek  
- Web güvenliği konularında uygulamalı deneyim kazanmak (hash, filtreleme, prepared statements)  
- Bootstrap ile responsive ve modern tasarım geliştirmek  

---

## 🛠 Kullanılan Teknolojiler
- **PHP** (backend ve güvenli form işlemleri)  
- **MySQL** (veritabanı yönetimi)  
- **HTML / CSS / Bootstrap** (frontend ve responsive tasarım)  
- **Güvenlik Özellikleri:** Password hash, prepared statements, veri filtreleme, form doğrulama  

---

## 📂 Proje Özellikleri
- **Kullanıcı Girişi / Kaydı:** Güvenli şekilde kullanıcı hesabı oluşturma ve giriş  
- **Admin Paneli:** Gönderi ekleme, düzenleme, silme  
- **Anasayfa:** Tüm gönderileri listeleme ve “Devamını Oku” ile detay sayfasına yönlendirme  
- **Detay Sayfası:** Her gönderi için içerik gösterimi
